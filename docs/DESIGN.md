# mylovart 视觉规范

风格：**中性、冷、克制**（Apple 灰 / Muji 那一挂）。判断标准只有一条——页面上除了黑白灰，几乎没有别的颜色。

---

## 色板

只有一套中性灰，没有第二套。

| 用途 | 值 |
|------|-----|
| 页面底 | `#F5F5F7` |
| 卡片 / 画布 | `#FFFFFF` |
| 主文字 | `#1D1D1F` |
| 次文字 | `#6E6E73` |
| 弱文字 | `#86868B` |
| 细线 | `#E4E4E7` |
| 强调（按钮/选中） | `#171717` |
| 危险 | `#DC2626` |

- **不用品牌色。** 强调色就是近黑，颜色出现在交互元素上，不出现在装饰上。
- **不引入暖色。** 米色、赭石、墨绿全部移除——一旦有暖色，整体就不冷了。
- 阴影用中性黑低透明度：`0 22px 54px -36px rgba(24,24,27,0.28)`。

## 字体

- 标题：Geist Sans `font-light`，`clamp(40px, 5.1vw, 72px)`，行高 1.12，字距 -0.035em
- 正文：13.5px / 1.95
- 标签：Geist Mono 9px / 字距 0.2em / 大写
- 不换字族，靠字重和字距做层级

## 版式

- 页头 80px，页脚一行等宽小字
- 主区 `max-w-[1160px]`，左文右卡，垂直居中
- 左栏：一句话标题 + 一行说明，除此之外什么都不放
- 登录卡：348px，白色，1px 细边框，大而柔的投影
- 大面积留白是设计的一部分，不要用图标或色块去填

## 背景

固定三层，缺一层就会显得单调：

1. **柔光**：两片白色 `blur 130px` 的光，一片压左上、一片压右下，把页面从纯平变成有空气。
2. **汇聚的细线**：这是唯一有"设计感"的元素。五条曲线从左下角汇入一个焦点（约 `x:340 / y:700`，正好落在左栏下方的空白里），再从焦点延伸一条带渐隐的线穿过整页。$`stroke-opacity` 0.16–0.18，用 `linearGradient` 做首尾渐隐，线上点几颗 2–3px 的小点，越远透明度越低。
3. **颗粒**：2.5% `feTurbulence` + 正片叠底，避免大面积纯色发塑料。

**不要动画。** 静态的冷感比动起来高级。

## 首页结构

- 版式：左栏 `1fr` + 右栏 `460px`，左栏 `h-full` 用 `flex-col`：字标置顶 → 内容居中 → 底部留白
- 登录卡：`p-10`、20px 标题、右上角 `SIGN IN` 等宽小字、底部一条细线分隔说明
- 页脚绝对定位在页面底部，跨两栏，等宽小字左标右年份

## 工作台

- 三栏之间只用 1px 细线分隔，不用阴影、不用圆角卡片
- Excalidraw 的紫色主题必须覆盖成中性色：`--color-primary`、`--color-surface-low/mid/high`、`--color-brand-hover/active` 都要改，只改 primary 不够
- 消息不用气泡，靠对齐和留白区分角色
