# mylovart 视觉规范

目标：**克制、有质感、像一个设计工作室做的东西**，而不是一个 SaaS 模板。

---

## 三条底线

1. **中文标题用宋体**。黑体（无衬线）在中文里天然偏「后台/工具」，衬线偏「编辑/出版」。首页、登录、空状态的标题一律 `font-serif`。
2. **页面上要有一件「作品」**。不是占位框、不是灰度示意，而是真的排版好的东西（海报、色卡、字体样张）。设计产品自己拿不出作品，说服力为零。
3. **留白要有节奏**。等距堆叠 = 表格。元素之间必须有不等的间距，靠细线和缩进制造分组。

---

## 色板

| 用途 | 值 | 说明 |
|------|-----|------|
| 纸底 | `#F2EFE6` | 首页底色，暖白偏米；比纯白有温度 |
| 画布白 | `#FFFFFF` | 登录区、卡片 |
| 主文字 | `#14140F` | 不用纯黑，带一点暖 |
| 次文字 | `#6B6B60` | |
| 弱文字 | `#9A9A8C` | |
| 细线（暖） | `#DDD7C9` | 首页分隔 |
| 细线（冷） | `#E8E8E4` | 工作台分隔 |
| 墨绿 | `#2F5D50` | 唯一强调色：按钮、选中、圆点 |
| 赭石 | `#C8622F` | 只出现在「作品」里，做视觉锚点 |

强调色和赭石**不同时大面积出现**。绿用于交互，橙用于内容。

## 字体

| 用途 | 字体 | 规格 |
|------|------|------|
| 中文标题 | 宋体（Songti SC / Noto Serif SC） | `clamp(40px, 4.8vw, 72px)`，行高 1.16，字距 -0.02em |
| 界面文字 | Geist Sans | 12–15px，行高 1.7–1.9 |
| 标签 / 编号 | Geist Mono | 9–11px，字距 0.14–0.20em，全大写 |

**小标签全部用等宽字体 + 大字距**，这是最便宜也最有效的「专业感」来源。

## 版式

- 首页左右分栏：`1fr 420px`，右栏纯白，左栏米纸
- 左栏内容最大宽度 560px，右侧留给作品
- 作品旋转 -4°，允许局部被边缘裁切（出血）
- 作品上方一行等宽小字标注编号和尺寸，像印刷品说明
- 标题下方一条 440px 细线，然后用段落 —— 线是节奏断点，不是装饰

## 组件

- 按钮：实心，高 36px，圆角 8px，hover 只降透明度
- 输入框：1px 细线，聚焦时边框变绿 + 2px 外环
- 不用卡片阴影堆叠；阴影只给「作品」这种真实的物体
- 登录区不做浮动卡片：整块白底 + 左侧细线，比卡片更干净

## 动效

- 交互反馈 150–200ms，`ease-out`，只动 opacity / transform
- 作品的阴影和旋转是静态的，**不加呼吸动画**（廉价感的来源）
- 尊重 `prefers-reduced-motion`

## 反面清单

渐变大按钮、玻璃拟态、大圆角卡片墙、彩色标签满屏、图标装饰、懂王式动效（抖动/弹跳）、假客户 logo 墙。
