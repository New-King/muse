# mylovart 视觉规范

目标：**克制、有质感、像一个设计工作室做的东西**，而不是一个 SaaS 模板。

---

## 三条底线

1. **首页要露出产品本身**，不是一张静态海报。设计工具的首页如果只有一个「作品」浮在纸上，会读成作品集或博客。正确做法是把作品放回画布：点阵背景、选中框、光标、工具栏、对话框，让人一眼知道这是能操作的东西。
2. **中文标题用无衬线，宋体只留给「作品」**。宋体是编辑语言，适合海报里的标题；把宋体放到产品标题上，整个页面会变成杂志/日记。
3. **留白要有节奏**。等距堆叠 = 表格。元素之间必须有不等的间距，靠细线和缩进制造分组。

---

## 色板

| 用途 | 值 | 说明 |
|------|-----|------|
| 页面底 | `#F7F6F2` | 首页底色，极淡暖灰；比纯白有层次，但不至于像纸 |
| 画布白 | `#FFFFFF` | 登录区、卡片 |
| 主文字 | `#14140F` | 不用纯黑，带一点暖 |
| 次文字 | `#6B6B60` | |
| 弱文字 | `#9A9A8C` | |
| 细线（暖） | `#DDD7C9` | 首页分隔 |
| 细线（冷） | `#E8E8E4` | 工作台分隔 |
| 墨绿 | `#2F5D50` | 唯一强调色：按钮、选中、圆点 |
| 赭石 | `#C8622F` | 只出现在「作品」里，做视觉锚点 |

强调色和赭石**不同时大面积出现**。绿用于交互，橙用于内容。

## 字体

| 用途 | 字体 | 规格 |
|------|------|------|
| 产品标题 | Geist Sans | `clamp(30px, 3.6vw, 48px)`，行高 1.2，字距 -0.03em |
| 作品标题 | 宋体（Songti SC） | 只出现在海报等「作品」内部，用 `cqw` 随容器缩放 |
| 界面文字 | Geist Sans | 12–15px，行高 1.7–1.9 |
| 标签 / 编号 | Geist Mono | 9–11px，字距 0.14–0.20em，全大写 |

**小标签全部用等宽字体 + 大字距**，这是最便宜也最有效的「专业感」来源。

## 版式

- 首页左右分栏：`1fr 400px`，右栏纯白，左栏淡暖灰
- 左栏：标题 + 两行说明 + 一块画布模拟
- 画布模拟是**横向铺满**的卡片，高度 440px（桌面），里面放 4–5 个真实对象：选中中的海报、文字图层、生成中的占位卡、色板、对话气泡
- 每个对象都要有「产品语言」：选中框 + 四角控制点、`海报 · 297×420` 标签、`生成中 62%` 进度、`TEXT · 思源宋体` 图层名
- 窄屏（< 640px）只保留海报和对话气泡，其余对象隐藏，避免互相压住

## 组件

- 按钮：实心，高 36px，圆角 8px，hover 只降透明度
- 输入框：1px 细线，聚焦时边框变绿 + 2px 外环
- 不用卡片阴影堆叠；阴影只给「作品」这种真实的物体
- 登录区不做浮动卡片：整块白底 + 左侧细线，比卡片更干净

## 动效

- 交互反馈 150–200ms，`ease-out`，只动 opacity / transform
- 作品的阴影和旋转是静态的，**不加呼吸动画**（廉价感的来源）
- 尊重 `prefers-reduced-motion`

## 反面清单

渐变大按钮、玻璃拟态、大圆角卡片墙、彩色标签满屏、图标装饰、懂王式动效（抖动/弹跳）、假客户 logo 墙。
