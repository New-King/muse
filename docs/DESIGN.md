# mylovart 视觉规范

目标：**安静、有质感、像设计工作室做的东西**。判断标准只有一条——把页面截图给别人看，对方会不会以为是 AI 生成的模板。

---

## 首页原则

1. **以文字为主。** 标题一句话说完，副文案一行。不要功能列表、不要三栏卖点、不要胶囊标签。
2. **不放假的产品截图。** 带小标签的「画布模拟」（工具栏、选中框、`生成中 62%`）是最典型的 AI 生成页面套路，一眼就廉价。要示意画布，就用**朦胧的色块和光**，让人感觉到"有东西在那里"，但看不清。
3. **背景要有空气感**，靠三层叠加实现：大面积柔光晕（blur 100px+）+ 极细弧线（透明度 0.05–0.07）+ 颗粒（3.5% 混合正片叠底）。颗粒是关键，没有它大面积渐变会像塑料。
4. **登录是浮在背景上的一块白**，不是页面切一半。半透明白色 + 细边框 + 大而柔的投影。

## 文案

- 标题 6–10 字，动词开头，不出现「AI」以外的技术词
- 副文案一行，写清楚做什么，不写怎么实现
- 不写"重新定义""赋能""一站式"这类词
- 大小写混排的英文标签一律等宽字体 + 0.2em 字距

## 色板

| 用途 | 值 |
|------|-----|
| 页面底 | `#F7F6F2` |
| 主文字 | `#14140F` |
| 次文字 | `#6B6B60` |
| 弱文字 | `#9A9A8C` |
| 细线 | `#E6E3DA` |
| 墨绿 | `#2F5D50` |
| 赭石 | `#C8622F`（只用于背景光晕，不做前景色） |

背景光晕只用这三种颜色的低透明度，不引入第四种。

## 字体

- 标题：Geist Sans，`font-light`，`clamp(40px, 5.1vw, 72px)`，行高 1.12，字距 -0.035em
- 正文：Geist Sans 13.5px / 1.95
- 标签：Geist Mono 9px / 字距 0.2em / 大写
- 中文不追求特殊字族；轻字重比换字体更能提升气质

## 版式

- 页头 80px，页脚一行等宽小字
- 主区 `max-w-[1160px]`，左文右卡，垂直居中
- 左栏标题与副文案之间留 32px，副文案与页脚之间留白最多
- 卡片宽 348px，内边距 28–32px

## 动效

- 不做背景动画。静态柔光比动起来更有质感
- 只有交互反馈：150–200ms，`ease-out`，只动 opacity / transform

## 反面清单

假产品截图、功能胶囊、三个卖点并排、渐变按钮、玻璃拟态、彩色图标、"AI 驱动"式口号、跟随鼠标的光斑。
