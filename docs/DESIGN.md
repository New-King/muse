# mylovart 视觉规范

风格：**中性、冷、克制**。判断标准只有一条——页面上除了黑白灰，几乎没有别的颜色。

---

## 色板

| 用途 | 值 |
|------|-----|
| 页面底 | `#F5F5F7` |
| 卡片 / 画布 | `#FFFFFF` |
| 主文字 | `#1D1D1F` |
| 次文字 | `#6E6E73` |
| 弱文字 | `#86868B` |
| 细线 | `#E4E4E7` |
| 强调（按钮/选中） | `#171717` |
| 危险 | `#DC2626` |

- 不用品牌色：强调色就是近黑，只出现在交互元素上
- 不引入暖色：米色、赭石、墨绿都不进色板
- 阴影只用中性黑低透明度：`0 22px 54px -36px rgba(24,24,27,0.28)`

## 字体

- 标题：Geist Sans `font-light`，`clamp(40px, 5.6vw, 84px)`，行高 1.1，字距 -0.04em
- 正文：13.5px / 1.95
- 标签：Geist Mono 9px / 字距 0.2em
- 不换字族，靠字重和字距做层级

## 首页版式

- 内容区 `max-w-[1040px]` 居中，栅格 `1fr 420px`，桌面间距 40px
- 标题顶部与登录卡顶部**始终对齐**：用
  `pt-[calc((100dvh-595px)/2-28px)]`
  （595 = 页面上下留白 152 + 卡片高度 443），窗口高度变化也保持齐平
- 移动端：单列，`content-start` 让行高贴合内容，标题与卡片间距 24px
- 登录卡：420px 宽，`p-10`，右上角 `SIGN IN` 等宽小字，底部细线分隔说明
- 页脚绝对定位，一行等宽小字

## 背景

只有两层，没有图形：

1. 两团白色柔光（`blur 130–150px`），一左上、一右下
2. 2.5% 颗粒（`feTurbulence` + 正片叠底），避免大面积纯色发塑料

不要加流动线、光斑、渐变网格——之前试过，都太吵。

## 唯一的动画：创作流程轨道

组件来自 [rare-ui rail-toc](https://www.rareui.com/components/railtoc)，本地仅加了一个 `autoLoop` 参数，其余保持原样。

- 位置：左栏，标题与说明之后，左对齐
- 内容：`描述需求 → 拆解意图 → 生成图像 → 生成视频 → 排版结构 → 导出成稿`
- 周期 9 秒：0–60% 指针走到终点；60–88% 停在终点；88% 起**只有指针淡出**；归位后淡入继续
- **轨道、节点、标签全程可见**，不做整块淡出
- `prefers-reduced-motion` 时停在终点，不播放

## 工作台

- 三栏之间只用 1px 细线分隔，不用阴影、不用圆角卡片
- Excalidraw 的紫色主题必须覆盖成中性色：`--color-primary`、`--color-surface-low/mid/high`、`--color-brand-hover/active` 都要改
- 消息不用气泡，靠对齐和留白区分角色
