# My Lovart 视觉规范

目标：**安静、留白、克制**。界面退后，内容在前。

---

## 基调

- 浅色为主，暖白底而不是纯白（`#FAFAF8`），长时间看不刺眼
- 文字近黑（`#17171A`），不用纯黑
- 只用一个强调色，其余全部靠灰阶层级
- 边框比阴影优先：`1px` 细线 > 投影
- 圆角统一：卡片 `12px`，控件 `8px`，小标签 `6px`

## 色板

| 用途 | 值 |
|------|-----|
| 背景 | `#FAFAF8` |
| 画布底 | `#FFFFFF` |
| 主文字 | `#17171A` |
| 次文字 | `#6B6B70` |
| 弱文字 | `#9A9AA0` |
| 边框 | `#E8E8E4` |
| 强调 | `#2F5D50`（墨绿，克制、不像 SaaS 模板） |
| 危险 | `#B4443C` |

强调色只用于：主按钮、当前选中项、焦点环。一屏最多出现两次。

## 字体

- 西文 / 数字：`Geist`，等宽用 `Geist Mono`（代码、ID、时间戳）
- 中文：`system-ui` 优先，回退 `PingFang SC`
- 正文 `14px / 1.6`，标题 `-0.01em` 字距
- 不引入第二个展示字族；层级靠字号和字重，不靠颜色

## 布局

- 三栏：左 `240px` 会话/项目，中自适应画布，右 `360px` 对话
- 栏间距 `1px` 分隔线，不用卡片嵌套
- 内容最大宽度 `720px`（对话区），两侧留白
- 间距用 4 的倍数：`4 8 12 16 24 32 48`

## 组件

- 按钮：默认描边、主操作用实心；高度 `32 / 36`，圆角 `8`
- 输入框：`1px` 边框，聚焦时边框变强调色并加 `2px` 外环
- 消息气泡：**不用气泡**，用对齐和间距区分角色；AI 消息左侧无头像
- 工具调用：折叠成一行细条（图标 + 名称 + 状态），点击展开
- 空状态：一句说明 + 一个主操作，不配插画

## 动效

- 交互反馈：时长 `150–200ms`，`ease-out`
- 只动 `opacity` 和 `transform`
- 流式文字不做逐字动画（会显廉价）
- 尊重 `prefers-reduced-motion`

### 首页背景

三层叠加，全部低透明度，目的是「有空气感」而不是「有特效」：

| 层 | 实现 | 参数 |
|----|------|------|
| 光晕 | 三个 `radial-gradient` 气泡 + `blur-3xl` | 墨绿 0.09 / 赭石 0.07 / 近黑 0.04 |
| 细线 | SVG 三次贝塞尔曲线，`stroke-dasharray: 3 17` | 透明度 0.22 / 0.14 / 0.08，22s / 34s / 16s 匀速流动 |
| 浮点 | 3 个 5px 圆点，上下浮动 12px | 9s / 13s / 7s，错开相位 |

节奏必须是**慢**的：一条线走完一次要 20 秒以上。快了就从「背景」变成「动画」。

## 首屏比例

- 主标题 `clamp(38px, 4.4vw, 66px)`，行高 1.14，字距 -0.035em
- 左栏内容最大宽度 640px，但预览卡片要撑到 540px，避免右半边空掉
- 右栏登录卡片固定 364px，外层留 480px 的渐变色底，形成「卡片浮在台面上」的层次

## 反面清单

不做：渐变按钮、玻璃拟态、大圆角卡片堆叠、彩色标签满屏、多余图标、加载时全屏 spinner。
