# M0 · 骨架

## 做了什么

- pnpm workspace + Turborepo，三个包：`apps/web`、`apps/server`、`packages/shared`
- `packages/shared` 定义 WebSocket 事件协议（`ClientEvent` / `ServerEvent`），前后端共用
- web：Next.js 15 + Tailwind v4，按 `docs/DESIGN.md` 搭出三栏工作区（左项目、中画布、右对话），数据全部静态占位
- server：Fastify，提供 `GET /health`
- `pnpm dev` 一条命令同时起 3000 / 3001

## 为什么

先立骨架和视觉基线，再填业务。视觉规则提前定死，避免写到一半退回模板脸；协议先定类型，后面接 WS 时前后端不用各写一套。
