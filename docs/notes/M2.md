# M2 · 界面可交互

## 做了什么

- 左栏项目列表可点击切换，当前项目高亮，切换即加载对应工作区
- 画布换成真的 Excalidraw：能画、能拖、能改，改动 600ms 防抖后存回服务端
- 对话能真的发出去：消息落库、调模型、回复渲染成 Markdown
- 服务端补了 `/workspace/:projectId` 三个接口（读、存画布、发消息）
- 修了两个问题：CORS 只放行 localhost 导致 127.0.0.1 下所有请求 Failed to fetch；Excalidraw 默认紫色主题与站点冲突，用 CSS 变量改成墨绿

## 为什么

先让「点得动、画得出、发得出去」这条闭环成立，再谈 Agent 工具调用。没有闭环时，后面接什么都是空中楼阁。

## 草稿项目

「新建项目」不再立刻写库，只在前端生成一个草稿（标记「未保存」）：

- 连续点多次只会有一个草稿，不会堆一排空项目
- 第一次真正产生内容（发消息、画东西）时才 `POST /projects`，并把发起的那句话截成项目名
- 没产生内容就切走，草稿直接丢弃，服务端没有残留

## 已知问题

- **AI 不能落笔**：模型只能在对话里给建议，没有 `generate_image` / `manipulate_canvas` 这类工具，画布上的东西全是手画的
- 数据还在内存里，重启即丢（Supabase 恢复中）
- 消息非流式，要等整段返回；长回复体感偏慢
- 没有登录，所有数据共用 `DEV_USER_ID`
