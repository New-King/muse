# M3 · 首页、登录与访问控制（仅界面）

## 做了什么

- `/` 首页改成左右分栏：左边是产品介绍和界面预览，右边直接是登录表单，不再有独立登录页
- 登录只接受 `NEXT_PUBLIC_OWNER_EMAIL`（默认 newking@example.com）；`/login` 保留为重定向，旧链接不会 404
- `/app` 工作台：未登录访问会跳回首页；左栏底部改成「退出登录」
- 会话存在 `localStorage`，键名 `mylovart.session`
- 窄屏下隐藏预览图和步骤说明，保证登录表单在首屏可见

## 为什么

先把「谁能进来」这条线在界面上立住，后面接 Supabase Auth 时只换校验实现，不动路由结构。

## 注意（这是占位，不是安全）

- 登录校验在**前端**：改一下 localStorage 就能绕过，密码也没校验。真实拦截必须在服务端做
- 接 Auth 时要改三处：登录页的校验、`RequireAuth` 的判断、服务端把 `DEV_USER_ID` 换成 token 里的 `sub`
- 暂未开放注册

## 已知问题

- 首页没有移动端细节打磨，窄屏只保证不崩
- 登录没有 loading 态、没有记住我、没有找回密码
